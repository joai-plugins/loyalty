# loyalty

Connect Loyalty to Claude, Cursor, and ChatGPT through JoAi's hosted MCP app server.

[Open app page](https://joai.ai/en/apps/loyalty) · [Browse all apps](https://joai.ai/apps)

## Works With

- ChatGPT
- Claude
- Codex
- Cursor
- Other MCP clients

## Install

### Claude

```bash
https://claude.ai/settings/connectors
/plugin install joai-loyalty@joai-claude-plugins
```

### Codex

Install this app from the official JoAi Codex marketplace in Codex.

`joai-loyalty`

If your Codex build only supports MCP registration, use the MCP endpoint below as a manual fallback.

### Cursor

Use the [Cursor install link](https://cursor.com/en-US/install-mcp?name=joai-loyalty&config=eyJ1cmwiOiJodHRwczovL2NvcnRleC5qb2FpLmFpL21jcC9hcHBzL2xveWFsdHkifQ%3D%3D) to install directly.



### ChatGPT

Paste the MCP URL in ChatGPT settings:

```
https://chatgpt.com/#settings/Connectors/Advanced
```
